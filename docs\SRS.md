# Software Requirements Specification (SRS) - Day 1
Project: Student Task Manager
Owner: maimonakhurshid07
University: AWKUM - BCS

### 1. Introduction
The Student Task Manager is a simple application to help AWKUM students manage their daily assignments, quizzes, and tasks. Currently students forget deadlines.

### 2. Objective
To build a system where a student can add, view, and manage tasks with due dates.

### 3. Users
1. Student (Primary User): Can add, edit, view, complete, delete tasks.
2. Admin: Can view all users (for future scope).

### 4. Functional Requirements
- F1: User Registration/Login using AWKUM email (e.g., maimona.khurshid@awkum.edu.pk)
- F2: Add Task: Title, Subject, Due Date, Description
- F3: View Task List
- F4: Mark Task as Complete/Pending
- F5: Delete Task

### 5. Non-Functional Requirements
- Simple UI
- Data should be stored securely
- System should be fast
